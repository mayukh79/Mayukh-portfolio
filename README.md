# Mayukh's Portfolio Website 🚀

This repository contains the code for my personal portfolio website. Dive in to explore the dynamic animations, 3D graphics, and modern UI practices I incorporated into my interactive digital resume!

---

## ⚙️ Tech Stack

React • TypeScript • GSAP • Three.js • WebGL • HTML • CSS • JavaScript

---

## 🛠️ Key Details

- **Custom 3D Animations**: Replaced static assets with a dynamic, custom `Three.js` particle-based sphere system that responds to cursor movement.
- **Production Ready GSAP**: All `gsap-trial` plugins have been completely rewritten with standard native `gsap` logic and custom DOM handlers to make the app production-ready and fully deployable without licensing friction.

---

## 💡 Running the Project Locally

To test out the portfolio website locally on your own machine:

```bash
# Install the necessary dependencies
npm install

# Run the development server
npm run dev
```
